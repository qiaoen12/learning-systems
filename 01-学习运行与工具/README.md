# 01｜学习运行与工具

这一分区解决“如何把学习变成可持续、可验证的实践”。它不是把生产力工具当作目的，而是让学习者具备用终端、版本控制和项目输出来学习的基本操作能力。

- 整理者：qiaoen12
- 整理日期：2026-08-24

## 本区顺序

1. [MIT Missing Semester](./01-mit-missing-semester.md)：第一优先级，和软件主线同时开始。
2. [OSSU Computer Science](./02-ossu-computer-science.md)：把它当长期课程地图，只阅读和选课，不全量开跑。
3. [Build Your Own X](./03-build-your-own-x.md)：完成基础编程后，只选择一个主题做重建练习。

## 并行规则

- Missing Semester 可以和任一软件课程并行。
- OSSU 是导航层，前 2–3 个月每周只安排一次检查，不取代主线课程。
- Build Your Own X 是项目挑战库；一次只开一个小目标，优先围绕当前正在学的概念。
