# 03｜计算机科学与系统思维

这一分区回答两个不同的问题：电脑从底层如何构成，以及复杂软件系统如何被拆解和权衡。它们的难度不同，不能同时当成初学者的主线。

- 整理者：qiaoen12
- 整理日期：2026-08-24

## 本区顺序

1. [Nand2Tetris](./01-nand2tetris.md)：有基础编程后，用“从 NAND 到计算机”的项目建立底层因果感。
2. [System Design Primer](./02-system-design-primer.md)：做过项目、理解基本数据结构之后，再把它用于自己项目的设计复盘。

## 使用原则

- Nand2Tetris 以连续完成模块为目标，避免只看硬件概念图。
- System Design Primer 以“给自己的项目写设计取舍”为目标，避免把它当面试八股库。
