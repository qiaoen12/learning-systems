## 7. 节点与关系数据契约

知识数据嵌入 HTML 的独立 JSON 数据块中，渲染逻辑不得硬编码节点名称。

每个节点至少包含：

```json
{
  "id": "stable-machine-readable-id",
  "parentId": "parent-id-or-null",
  "level": 3,
  "nameEn": "Operating Systems",
  "nameZh": "操作系统",
  "sourceClass": "CS2023",
  "stability": "stable",
  "summary": "稳定定义",
  "boundary": "本节点包含与不包含什么",
  "learningOutcomes": [],
  "evidence": [],
  "sourceIds": [],
  "lastVerified": "2026-07-14",
  "children": []
}
```

来源记录至少包含：

```json
{
  "id": "source-id",
  "tier": "A",
  "title": "来源标题",
  "organization": "发布组织",
  "url": "https://...",
  "version": "版本或状态",
  "publishedAt": "YYYY-MM-DD",
  "verifiedAt": "2026-07-14",
  "locator": "章节或页码"
}
```

允许的关系类型：

- `part_of`：主层级归属。
- `requires`：概念或能力前置。
- `applied_in`：应用关系。
- `crosscuts`：横切多个领域。
- `contrasts_with`：需要对照理解。
- `verified_by`：对应掌握证据。
- `supersedes`：新版概念替代或修订旧概念。

默认只显示 `part_of`。选中节点后才突出显示其跨域关系，避免总图连线过密。

## 8. 交互规格

### 8.1 初始状态

- 根节点和六个第二层节点可见。

### 8.2 单击行为

- 有子节点且处于折叠状态：单击后展开直接子节点。
- 有子节点且处于展开状态：再次单击后折叠全部后代。
- 叶子节点：单击后选中并打开详情面板。
- 展开或折叠节点时同时更新 URL hash 和无障碍状态。
- 单击新分支不会自动折叠其他分支；用户可同时比较多个分支。

### 8.3 必备控制

- 收起全部：恢复根节点 + 第二层状态。
- 回到全局：取消选中并定位根节点。
- 搜索：查找中英文节点，选择结果后自动展开祖先路径。
- 前进 / 后退：浏览器历史可恢复展开路径和选中节点。
- 适配、放大、缩小。
- 图谱 / 大纲切换。
- 来源与方法说明。

### 8.4 URL 状态

URL fragment 至少编码：

- 已展开节点 ID。
- 当前选中节点 ID。
- 当前视图模式。

无效、过期或不存在的 ID 必须安全回退到初始状态，不能出现空白页面。

### 8.5 详情面板

节点详情至少显示：

- 中英文名称。
- 稳定定义与边界。
- 来源分类：CS2023 或 2026 扩展。

关键内容不能只依赖 hover 展示。

## 9. 可视化与渲染设计

### 9.1 图类型

- 主结构：有根有序树。
- 辅助结构：少量有方向跨域关系。
- 主要阅读任务：父子层级、逐级下钻和依赖追踪。

### 9.2 布局

首选：稳定的左到右分层树布局，节点顺序固定，边采用正交或低弯折折线路由。

原因：

- 中英文节点标签较长。
- 展开和折叠时需要保持用户的空间记忆。
- 力导向图会导致节点位置漂移，不适合知识目录探索。
- 放射状布局在深层级和长标签下可读性较差。

后备：同步层级大纲。任何图谱无法清楚显示的内容都必须能从大纲完成浏览。

### 9.3 渲染技术

- 单个 SVG 或 SVG + HTML 节点混合渲染。
- 使用原生 JavaScript 实现确定性布局和交互。
- 不使用 Canvas、WebGL、3D 或物理动画。
- 只渲染当前可见节点和边，折叠后代不进入 DOM。
- 预计知识实体总量可达到 200–500，但默认可见节点不超过 7。

### 9.4 色彩角色

- 中性背景：画布和未选中关系。
- 主强调色：CS2023 稳定主干。
- 对比色：2026 动态扩展。
- 选中色：当前节点和祖先路径。
- 警示色：来源冲突、候选或待核验内容。

颜色必须配合文字、线型或标签，不能单独承担语义。

### 9.5 动效

- 仅用于展开、折叠和路径高亮。
- 150–250ms，不能改变最终节点顺序。
- 支持 `prefers-reduced-motion`，关闭动画后功能完整。
