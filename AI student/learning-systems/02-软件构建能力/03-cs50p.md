## 它解决什么问题

CS50P 用 Python 教编程本身：函数、条件、循环、异常、库、单元测试、文件 IO、正则、面向对象。每周有讲座、习题集和自动评分，最后有一个自选项目。

它在这份地图里的位置很明确：**如果你的目标是 AI 应用工程，这门课取代 The Odin Project 和 freeCodeCamp 作为主线。**

原因是语言和领域都对齐。Odin 的路径是 HTML/CSS/JavaScript 然后 Node 或 Rails，freeCodeCamp 的主干也是 Web 前端——两者都是完整且优秀的课程，但通往的是 Web 开发岗位。而 AI 工程链路上的每一环，从数据处理、API 服务到模型调用、检索和评测，默认都在 Python 生态里。走 Web 主线再转 Python，中间那几百小时不会白费，但也不在通往目标的直线上。

## 何时开始

零基础可以直接开始，和 [MIT Missing Semester](../01-学习运行与工具/01-mit-missing-semester.md) 同时进行。唯一的前置是能在自己电脑上打开终端并创建文件。

## 建议的学习方式

**习题集必须自己做完再看任何参考答案。** 这门课的价值几乎全在习题上，讲座只是让习题变得可做。跳过习题看讲座，等于什么都没学。

从第一周开始就在本地写代码，不要只用课程提供的在线环境。在线环境屏蔽了环境配置、依赖安装和路径问题，而这些恰好是初学者后面最常卡住的地方，早点遇到反而好。

每周结束时把当周代码提交到自己的 Git 仓库，配合 Missing Semester 学到的命令。这样一门课下来，你同时有了编程能力和一份真实的提交历史。

## 最小验收

- 能独立写出 50 行以上、有函数拆分的 Python 脚本。
- 能解释 list 和 dict 的区别，以及脚本从哪一行开始执行。
- 能独立定位并修复缩进、变量名、类型三类基础错误。
- 完成最终项目，且能讲清它做什么、怎么运行、哪里卡过。

## 并行与下一步

与 Missing Semester 并行。学完之后主线 B 的下一步是 Web 与服务：先用 `requests` 调通别人的 API，再用 FastAPI 官方教程写出自己的第一个服务，然后接 SQLite 让数据能存下来。

这三步没有单独收录成条目，因为官方文档已经是最好的材料，不需要中间层。做完它们就可以进 [06 AI 工程与产品能力](../06-AI工程与产品能力/README.md)。

想补计算机原理的，可以每周一次并行 [Nand2Tetris](../03-计算机科学与系统思维/01-nand2tetris.md)，但对主线 B 不是必需。

## 现在不做什么

不要同时上 CS50P 和 Odin 或 freeCodeCamp。三者都是完整主线，并行只会都做不完。

也不要因为"CS50x 名气更大"就改上 CS50x。那门课用 C 语言讲计算机科学导论，更硬也更慢；除非你确实想要那份底层理解，否则 CS50P 是更直接的路径。
