## 它解决什么问题

该课程用多节 Learn 和 Build 课程介绍生成式 AI 概念，并提供 Python、TypeScript 和应用代码。它适合已经能写基础程序、想先把模型 API 变成小应用的人。

## 何时开始

完成变量、函数、文件读写、Git 和一个基础程序后开始。若当前软件主线已经接触 HTTP 或 API，会获得更完整的理解。

## 建议的学习方式

每次选一节包含代码的课程：先跑通示例，再把它改成一个与自己相关的小场景，例如笔记提取、文档问答或分类助手。记录输入、输出、失败案例和成本/延迟等观察。

## 最小验收

- 本地运行并修改一个课程示例。
- 做出一个有明确输入、处理和输出的生成式 AI 小应用。
- 至少处理一个错误输入、失败响应或不可用 API 的情况。

## 并行与下一步

可以与软件主线的 API 学习并行。完成一个应用后，转到 Karpathy 了解模型原理；想优先训练模型的人可改选 fast.ai，而不是两条应用入口同时全修。

## 现在不做什么

不要把 Azure 或其他特定平台配置本身当作核心能力；优先理解应用输入、模型调用、输出验证和失败处理的通用结构。
