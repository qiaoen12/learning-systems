## 它解决什么问题

Cookbook 是可运行的示例集合，覆盖结构化输出、function calling、embedding、批处理、重试与限流、流式响应、成本控制等模式。它不教概念，教的是“这件事在真实代码里长什么样”。

对刚开始接 API 的人，它最大的价值是消除一类特定的挫败：知道要做什么，但不知道请求该怎么组织、错误该怎么接、返回该怎么校验。这些在概念课里通常一带而过。

## 何时开始

会写 Python 脚本、发过 HTTP 请求之后。第一次调用模型 API 的那一周就可以打开。

## 建议的学习方式

**永远带着一个具体问题进来。** 正确的用法是“我要让模型返回固定 JSON，去找结构化输出那一篇”，而不是从目录第一篇往下读。

找到示例后不要直接抄。先自己写一版，跑不通或不稳定时再对照示例，然后把差异写下来——差在哪一步、为什么那样写更稳。这个差异记录比示例代码本身有价值。

虽然是 OpenAI 官方仓库，绝大多数模式对任何 OpenAI 兼容接口都通用。用其他供应商时，注意区分哪些是通用模式、哪些是该家特有的参数。

## 最小验收

- 能让模型稳定返回可解析的结构化结果，并在解析失败时有兜底。
- 能给一次 API 调用加上超时、重试和错误分类。
- 能记录单次调用的 token 消耗和延迟。

## 现在不做什么

不要把它当课程排进周计划。它有几百篇示例，通读一遍既做不到也没意义，而“我要读完 Cookbook”正是把学习变成收藏的典型开头。
