## 它解决什么问题

MIT Missing Semester 教的是许多入门编程课默认你已经会、却常常没人系统教的电脑工作能力：Shell、命令行工具、Git、调试、编辑器、自动化、测试、构建和开发环境。它让“会点按钮”和“能独立排查、复现、提交代码”之间有一条清晰的练习路径。

## 何时开始

可以从第一天开始，不要求先会 Python 或 Web 开发。只要能在自己的电脑上打开终端、创建文件并愿意记录命令即可。

## 建议的学习方式

先完成 Shell、命令行工具、Git 与调试四部分的练习；每学一个命令，就在自己的练习项目里真实使用一次。不要把命令清单背下来，而要保留一份“我用它解决过什么问题”的记录。

## 最小验收

- 能在终端中定位文件、搜索文本和创建目录。
- 能初始化一个 Git 仓库，完成一次有意义的提交。
- 遇到报错时，能复现问题、读错误信息并写下排查过程。

## 并行与下一步

与 The Odin Project 或 freeCodeCamp 同时开始。掌握基本 Git 后，再用这些能力支持 Nand2Tetris、AI Notebook 和后续项目。

## 现在不做什么

不要一开始就追求 Vim、复杂 shell 配置或全套 DevOps 工具；先让终端和 Git 真正服务于当前项目。
