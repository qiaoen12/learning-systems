# 周报

命名：`week-01.md` 起，按自然周编号，不按层。
模板：`../../current/03-execution.md` 第 4 节，直接抄。

只要三行加一个数字。旧方案那个八小节模板已取消——它从未被填写过一次。

第 4 行「语料这周多了什么」只允许一句话。**展开成文档就撞上入口阀门的元文档禁令**，见 `../../current/01-guardrails.md` 第 5.3 节。

```markdown
## Week N（日期范围） · 当前层：Lx

1. 本周判据前进了什么：
2. 卡住的一处，根因是：
3. 哪一步明显是 AI 帮我兜过去的：
4. 语料这周多了什么，使它更接近可用于研究或产品：

数字：pytest 通过 __ / __ ，覆盖 __ 个频道，断电测试最高级 跑 / 读 / 修 / 写 / 未做，语法输入累计 __ 小时
入口阀门：未触发 / 已触发（触发日期：）
```

写不出第 2 行（没卡住）比写不出第 1 行更值得警惕——通常意味着这一周没碰真问题。
