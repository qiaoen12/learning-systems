# 05｜组织与公司能力

软件和 AI 产品不会只靠个人代码运行。真实公司 Handbook 能让学习者看到招聘、协作、决策、管理、支持和事故处理如何落到制度上。

- 整理者：qiaoen12
- 整理日期：2026-08-24

## 本区使用方式

- 从任何技术阶段起，每周选一个主题阅读 30–60 分钟。
- 以问题阅读，例如“远程协作怎么做”“管理者怎样支持工程团队”，不要从第一页线性背制度。
- 对同一主题同时看两家公司，写出共同点、差异和可能的适用条件。
