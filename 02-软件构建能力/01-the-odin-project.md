## 它解决什么问题

The Odin Project 用连续项目组织 Web 开发学习：基础知识、HTML/CSS、JavaScript、数据库、Node 与完整 Web 项目逐步推进。重点不是读完教程，而是持续自己写项目，最终形成能展示的作品集。

## 何时开始

可以在完成或同步进行 MIT Missing Semester 的 Shell 与 Git 入门后开始。没有编程基础也可以从 Foundations 段进入。

## 建议的学习方式

按照课程项目顺序走。每完成一个项目，自己写一段说明：目标、使用的技术、卡住的地方、如何验证。遇到资料搜索时先自己定位问题，再查文档或提问。

## 最小验收

- 独立完成一个前端或小型全栈项目，而非只跟抄视频。
- 项目有清晰 README、可运行方式和 Git 提交记录。
- 能向同学解释一个自己作出的技术选择。

## 并行与下一步

与 MIT Missing Semester 并行。学完基础编程并完成一个项目后，可每周并行一次 Nand2Tetris；需要 AI 应用时再接 Microsoft Generative AI for Beginners。

## 现在不做什么

不要同时把 freeCodeCamp 也当完整主线。两套路径内容重叠，二选一能减少切换成本。
