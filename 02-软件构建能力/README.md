# 02｜软件构建能力

这一分区的目标是让初学者尽早获得“自己做出能运行、能展示的软件”的体验。它包含两条相似的全栈学习路线，因此要**二选一作为主线**，而不是并行刷完。

- 整理者：qiaoen12
- 整理日期：2026-08-24

## 选择建议

| 更看重什么 | 选哪条主线 | 原因 |
| --- | --- | --- |
| 深度项目、作品集、较完整的 Web 路径 | [The Odin Project](./01-the-odin-project.md) | 项目连续性强，适合愿意自己查资料和做项目的人 |
| 互动练习、较短反馈、课程平台与认证结构 | [freeCodeCamp](./02-freecodecamp.md) | 练习、测试和项目节点更显性，适合需要即时反馈的人 |

## 与其他分区的关系

- 和 MIT Missing Semester 同时开始。
- 做出第一个项目后，再进入 Nand2Tetris、Build Your Own X 和 AI 应用课程。
- 不是必须走 Web 开发职业路线；本区的更普遍价值是获取编程、调试、Git 和项目交付的基本能力。
