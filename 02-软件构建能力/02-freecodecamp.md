## 它解决什么问题

freeCodeCamp 提供由互动课程、练习、Workshop、Lab、测验、项目与认证组成的学习平台和开源课程代码。它适合需要更短反馈周期、希望先通过题目和小项目建立节奏的初学者。

## 何时开始

可从零开始；同时补上 MIT Missing Semester 的终端与 Git 基础，避免只在网页课程环境中操作而不会管理真实代码项目。

## 建议的学习方式

以一个模块的项目和测验作为完成点，不以看完多少视频或刷了多少题作为完成点。把每个 required project 放进自己的 Git 仓库，并补充一项自行扩展的小功能。

## 最小验收

- 完成一个模块的项目和相应测验。
- 能在本地运行、修改并提交自己的项目。
- 至少有一项不按教程原样实现的功能或设计改动。

## 并行与下一步

与 MIT Missing Semester 并行。完成基础模块与一个项目后，可进入 Nand2Tetris 或 Microsoft Generative AI for Beginners。

## 现在不做什么

不要把认证当作唯一目标，也不要和 The Odin Project 全量并行。若后续想转向项目密度更高的路线，可以在一个明确模块结束后再切换。
